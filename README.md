A one-line elevator pitch from a city pigeon to investors for its startup, Coo.ly — Yelp for statues, written by the pigeons who have been reviewing every monument in the city for centuries.

## Run it

```sh
python3 main.py
```

Writes the pitch (167 characters, one line) to `/output/entry.txt`.
